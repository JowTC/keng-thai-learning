# เก่งไทย

เว็บฝึกภาษาไทยสำหรับนักเรียนระดับเริ่มต้น ใช้งานได้บนคอมพิวเตอร์และ iPad

## ความสามารถหลัก

- แยกพื้นที่คุณครูและนักเรียนด้วย PIN และรหัสนักเรียน
- แบบทดสอบ 4 ระดับ สุ่ม 8 ข้อใหม่จากคลัง 140 ข้อในแต่ละรอบ
- ครอบคลุมพยัญชนะไทย 44 ตัวและสระ 32 รูปเสียง
- คลังฝึกอ่าน 80 แบบฝึก พร้อมเสียงอ่านช้าและการสะกดหลังตอบ
- กระดานฝึกเขียนด้วยนิ้วหรือ Apple Pencil
- หน้าคุณครูสำหรับดูผล วิเคราะห์จุดที่ควรฝึก และมอบหมายการบ้าน
- เก็บข้อมูลบน Netlify Blobs เพื่อให้ครูและนักเรียนใช้คนละเครื่องได้

## เริ่มใช้งานในเครื่อง

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` แล้วตั้ง PIN คุณครูครั้งแรก

## เผยแพร่บน Netlify

โครงการนี้ตั้งค่า `netlify.toml` และ Next.js App Router ไว้แล้ว กำหนดตัวแปรลับ `INITIAL_TEACHER_PIN` เป็นตัวเลข 6–12 หลักใน Netlify ก่อนเผยแพร่ครั้งแรก ข้อมูลห้องเรียนจะถูกเก็บใน Netlify Blobs ของเว็บไซต์
